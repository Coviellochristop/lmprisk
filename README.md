# LMP Alternative Risk Website

Static, GitHub-ready website for LMP Alternative Risk.

## Files

- `index.html` — page structure and content
- `styles.css` — all site styling and responsive rules
- `script.js` — mobile navigation behavior
- `source-original.html` — original Claude-generated single-file version for reference

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload the files in this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

The site uses Google Fonts and one externally hosted hero image, so those assets require an internet connection. For a fully self-contained deployment, download the hero image into an `assets` folder and update its path in `index.html`.
